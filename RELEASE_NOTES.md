CyberFoil Nexus uses the official CyberFoil 1.5.1 version number.

- Install from an external USB drive and choose USB Drive, SD Card or Internal Storage as the destination. The header shows the USB drive’s free space.
- Fixes USB-to-USB installs that could stop with error `0x00000202` when reading a game’s manifest.
- The app checks this repository at startup and prompts when a newer Nexus build is available. You can also check in Options. Updates are verified before replacing the running app.

**First install or upgrade from the earlier local build:** Extract the ZIP to your microSD, or replace your existing CyberFoil Nexus NRO with the NRO below. Open CyberFoil Nexus from hbmenu. Users with this release installed can accept future updates in the app.
